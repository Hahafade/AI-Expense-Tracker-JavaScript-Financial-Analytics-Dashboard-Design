# AI Expense Tracker

A resume-friendly business analytics project that turns raw expense notes into categorized transactions, dashboard charts, and AI-style spending recommendations.

## Features

- Parse pasted expenses such as `Uber Eats - $23`
- Automatically categorize spending with keyword-based AI logic
- Show total spend, budget status, largest category, and average transaction
- Visualize category mix and monthly spending trend
- Generate business-style insights and budgeting recommendations
- Export categorized transactions as CSV

## How to Run

Open `index.html` in a browser. No install step is required for the MVP.
